# Use compact day restrictions in scene names

Scene Schedules express Day Restrictions as bare day abbreviations or inclusive ranges inside the option list, using commas to separate both days and other options—for example, `12:00 [Mo-Th,Su,i]`. Day abbreviations are already unambiguous, so omitting a prefix and using one separator keeps names compact and easier to enter; the parser combines all day entries regardless of their position, while migration writes days first, compresses consecutive days into ranges, and omits the restriction for daily schedules. Unknown options and invalid values make the scene ineligible for scheduling; the unreleased `d:` and semicolon syntax is not supported, and input-file syntax is unaffected.
